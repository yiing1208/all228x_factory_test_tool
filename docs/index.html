下載後點兩下就能用

Windows 10／11（64 位元），不需要安裝 Python 或其他軟體

  1. 下載 all228x_factory_test_tool_v5.exe
  2. 放在可以寫入的資料夾（例如桌面），結果檔會存在 exe 旁邊
  3. 點兩下開啟，啟動時要先解壓，約需 2～5 秒
  4. 跳出 SmartScreen：點「其他資訊」→「仍要執行」

    每台會依序執行

    要注意

      自訂指令會先讓你確認

      按 Start 後跳出確認視窗，按「否」就不會開始

      1. 確認視窗會顯示：完整指令、timeout、IP 數量
      2. 多道指令要寫在同一行，用 && 或 ; 串接
      3. 指令裡有 sudo：設備必須設定 sudo 免密碼，否則略過那台
      4. 確認無誤再按「是」

      時區、鍵盤勾選才會改

      沒勾就不會動到設備設定

      1. 勾「更改時區」或「更改鍵盤佈局」，再選要改成的值
      2. 「完成後重開機」預設是勾起來的，但只有勾了時區或鍵盤時才會重開
      3. 改之前會先做檢查，改完會讀回來驗證
      4. 任一步失敗：這台就停止，不跑測試、不寫結果檔

      每台自動跑完這幾步

      灰色虛線的步驟代表沒勾選，會直接跳過

      按「正常跑一台」或「模擬失敗」看看。

      stress／allhicom 的指令回傳錯誤碼時不會停，一樣會寫結果檔，錯誤只記在 Log。

      結果檔：一行就是一台跑完的設備

      檔名是開始時間 YY-MM-DD-HHMM.txt，每跑完一台就馬上寫入
